Agent Deck

Firmware v__VERSION__ · ESP32-S3

Firmware for the SenseCAP Indicator D1: a 4" touch screen that shows the Claude Code sessions running on your Mac and brings the one you tap to the front. The Mac side is the agent-deck program from the same repository.

  1. Connect the Indicator to this computer with a USB-C data cable.
  2. Quit agent-deck if it is running: it holds the serial port.
  3. Press Install and pick the CH340 port (USB Serial / usbserial-…).

This browser can't flash devices. Use Chrome or Edge on desktop (Web Serial). Web Serial needs a secure (https) page.

Needs Chrome or Edge on desktop (Web Serial). The image is written at offset 0 and replaces whatever the ESP32-S3 had. Prefer the command line? espflash write-bin 0x0 agent-deck-firmware_*_esp32s3.bin with the file from the latest release.

Start screen

Put your own picture or animation on the screen the deck shows while your Mac isn't connected: a GIF, animated WebP or PNG, or a still PNG or JPEG. Fit it here, then write it to the deck. It stays there when you update the firmware.

The picture and the deck's hint below it are laid out together; drag the preview to move them, zoom to resize the picture. Fewer colours make the file smaller and quicker to write.

Quit agent-deck on your Mac first: it holds the serial port. Needs firmware v__VERSION__ or later. From the command line: espflash write-bin 0x400000 agent-deck-start-screen.bin.
